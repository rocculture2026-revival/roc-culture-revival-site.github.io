隱私權政策

中華民國文化復興聯盟　最後更新：2026 年 10 月 30 日

本網站

本網站為靜態網頁，不使用 Cookie、不放置追蹤或分析程式，也不收集訪客的任何個人資料。

本聯盟的發文工具

本聯盟使用自行撰寫的發文工具，將本聯盟自己製作的文章、圖片與影片，發布到本聯盟自己的 Instagram、Threads、Facebook 粉絲專頁、YouTube 頻道、X 與 TikTok 帳號。

  • 此工具只存取本聯盟自有的帳號，不存取、不收集任何其他使用者的資料。
  • 使用 YouTube API 服務時，僅使用上傳影片的權限（youtube.upload），不讀取頻道觀眾或其他使用者的資料。
  • 使用 TikTok API 時，僅使用基本帳號資訊與發布影片的權限（user.info.basic、video.publish）。
  • 存取權杖以加密方式保存在 GitHub Secrets，不會公開，也不會分享給第三方。

本工具使用 YouTube API 服務，使用時亦適用 YouTube 服務條款 與 Google 隱私權政策。如需撤銷授權，可至 Google 帳戶的安全性設定 移除。
