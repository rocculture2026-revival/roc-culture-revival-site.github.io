TikTok 授權（聯盟內部使用）

1. 貼上 TikTok 開發者後台的 Client key，按「前往授權」，用聯盟的 TikTok 帳號登入並同意。

2. 授權完成。這個授權碼約 10 分鐘內有效，請馬上在自己電腦的終端機（Mac：「終端機」；Windows：PowerShell）貼上下面這行，並把 貼上_CLIENT_SECRET 換成你的 Client secret：





3. 執行後會回傳一段文字，複製其中 "refresh_token":"…" 引號裡的值，存到 GitHub Secrets 的 TIKTOK_REFRESH_TOKEN_MAIN。不要貼到聊天或其他地方。
